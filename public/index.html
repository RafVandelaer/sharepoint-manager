App Registratie Setup

1. Azure App Registratie

Maak een nieuwe app registratie aan in Azure Portal:

  • Ga naar Azure Portal - App registrations
  • Klik op "New registration"
  • Naam: "SharePoint Manager"
  • Redirect URI: http://localhost:3000/auth/callback

2. API Permissions

Je moet Application permissions kiezen (niet Delegated permissions):

Application permissions
Je applicatie draait als service en heeft toegang tot alle SharePoint sites in de tenant, zonder dat een gebruiker is ingelogd.
Delegated permissions
Niet geschikt voor deze tool. Vereist een ingelogde gebruiker en geeft alleen toegang tot sites waar die gebruiker rechten heeft.
  • Sites.Read.All (Application)
  • Sites.ReadWrite.All (Application)
  • Sites.Manage.All (Application)

Vergeet niet om admin consent te geven!

3. Client Secret

Maak een client secret aan en kopieer de waarde.

4. Environment Configuration

Maak een .env bestand aan met:

TENANT_ID=jouw-tenant-id
CLIENT_ID=jouw-client-id
CLIENT_SECRET=jouw-client-secret
PORT=3000
REDIRECT_URI=http://localhost:3000/auth/callback
GRAPH_API_URL=https://graph.microsoft.com/v1.0
