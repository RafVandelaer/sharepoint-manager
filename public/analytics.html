Library Versioning Info

Versioning Settings Must Be Changed in SharePoint

Microsoft Graph API does not support updating versioning settings. This requires a SharePoint-scoped token which needs different authentication.

💡 Quick access: Click the icon next to each library below to open its settings in SharePoint.

Loading libraries...

How to Change Versioning Settings:

  1. Click "Open in SharePoint" button below
  2. Navigate to the library you want to configure
  3. Click the gear icon () → Library Settings
  4. Click "Versioning settings" under General Settings
  5. Set "Number of major versions to retain" (e.g., 100-500)
  6. Click OK to save
